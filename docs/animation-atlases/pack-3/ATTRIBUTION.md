# Pack 3 attribution

Digital restorations, edited for this project.

This notice covers the ten canonical source restorations selected for pack 3
and their project derivatives: the prepared atlas PNGs in this directory, the
registered six-frame runtime packs, and the `moving-images.gif` review montage.
For this pack, those restored sources and derivatives are offered under
[CC BY-SA 4.0](https://creativecommons.org/licenses/by-sa/4.0/).

The restorations come from the [Fugleramme classic artwork repository](https://github.com/arnegiacomo/fugleramme),
its [classic manifest](https://raw.githubusercontent.com/arnegiacomo/fugleramme/main/assets/artwork/classic/manifest.json),
and its [upstream attribution](https://raw.githubusercontent.com/arnegiacomo/fugleramme/main/assets/artwork/classic/ATTRIBUTION.md).
The upstream WebP is the identity reference for each item. The historical
plate link in the table records the selected original source named by the
project inventory.

The generated pose changes are AI-generated adaptations of each reference,
drawn as six discrete anticipation, action, and release states. The project
also removes the paper background, registers each pose to a fixed cell and
baseline, and assembles the atlas, runtime frames, and montage. These changes
are part of the project derivatives covered above; they do not claim that the
historical scans or original plates all have the same license.

The repository's code, runtime, and other assets are not relicensed by this
notice. See the upstream attribution for the individual historical works and
their original terms.
