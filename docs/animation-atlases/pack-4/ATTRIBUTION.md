# Pack 4 attribution

Digital restorations, edited for this project.

This notice covers ten pack 4 source restorations and their project derivatives.
Derivatives include the prepared atlas portable network graphics files, registered six-frame runtime packs,
and the moving-images.gif review montage. This project offers those sources and
derivatives under [CC BY-SA 4.0](https://creativecommons.org/licenses/by-sa/4.0/).

The restorations come from the
[upstream classic artwork repository](https://github.com/arnegiacomo/fugleramme),
its [classic manifest](https://raw.githubusercontent.com/arnegiacomo/fugleramme/main/assets/artwork/classic/manifest.json),
and its [upstream attribution](https://raw.githubusercontent.com/arnegiacomo/fugleramme/main/assets/artwork/classic/ATTRIBUTION.md).
The upstream WebP is each item's identity reference. Each item below links its
selected historical plate.

The project makes two changes to each reference. First, AI generates six pose
adaptations for one short activity. Second, the project removes the paper
background and registers each pose to a fixed cell and baseline. The atlas,
runtime frames, and review montage include these changes.

The CC BY-SA 4.0 scope covers these ten restorations and their atlas, frame,
and montage derivatives. Historical publications and scans can have different
terms. This notice leaves those terms unchanged. Repository code and other
assets retain their existing licenses.
